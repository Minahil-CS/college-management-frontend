# 🎓 Apex College of Science & Technology — College Management Frontend

A modern, responsive, single-page **College Management System** web interface built using **HTML5, Tailwind CSS, and Vanilla JavaScript**. Designed to streamline academic administration and campus navigation, it provides interactive directories for departments, courses, faculty, students, campus events, and an integrated ERP Portal drawer.

---

## ✨ Key Features

- **🏛️ Institutional Navigation & Global Search:** Sticky navbar with scroll-spy active links, live campus announcement ticker, mobile drawer menu, and a `Ctrl/Cmd + K` quick-search modal.
- **🔐 ERP Portal Command Drawer:** Interactive slide-over dashboard supporting **Student** and **Admin** role views with quick campus actions.
- **🏢 Academic Departments:** Showcases 6 multidisciplinary schools with lab highlights and detailed curriculum modals.
- **📚 Filterable Course Catalog:** Real-time search and filtering by department and degree level (`BS`, `MS`, `PhD`, `Diploma`) with syllabus preview modals.
- **👩‍🏫 Faculty Directory:** Searchable faculty profiles displaying research areas, office hours, and one-click email copy functionality.
- **👨‍🎓 Student Records & SGPA Calculator:**
  - Filterable student directory with digital transcript preview cards.
  - **Add Student Record** modal for dynamically adding new student entries to the interface.
  - Built-in interactive **SGPA Calculator** for instant GPA computation.
- **📅 Events, Notices & Admissions:** Category-filtered campus events with live seat RSVP counters, an institutional notice board, and a validated admission inquiry form with toast notifications.

---

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Styling:** Tailwind CSS (via CDN), Custom CSS
- **Interactivity:** Vanilla JavaScript (ES6+)
- **Icons & Typography:** Font Awesome 6, Google Fonts (`Plus Jakarta Sans` & `Inter`)
